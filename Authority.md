**Important Considerations Before Use:**

1.  **Secrets Management:** `JWT_SECRET_KEY` and `FERNET_KEY` **MUST** be strong, unique, kept secret, and managed securely (e.g., via environment variables in production, NOT committed to version control).
2.  **MFA Secret Encryption:** While encryption is implemented using Fernet, the security relies entirely on keeping the `FERNET_KEY` secret.
3.  **WebAuthn:** This library provides the *backend framework*. You **must** implement the client-side JavaScript interactions using the options generated by this library.
4.  **HIBP:** Requires internet access for the API check or careful management of the offline database. Consider the privacy implications and failure modes (`HIBP_FAILURE_MODE`).
5.  **Database:** SQLite is used by default. For high-concurrency production systems, consider implementing a storage adapter for PostgreSQL or MySQL using the provided `StorageInterface`.
6.  **Email/SMS Sending:** The library triggers events (`on_user_registered`, etc.). You need to implement listeners in your application to actually send emails/SMS with tokens.
7.  **Testing:** The provided tests are foundational. Thorough testing, especially for security-sensitive components, is crucial before production deployment.
8.  **Dependencies:** Ensure all dependencies listed in `pyproject.toml` are installed.

# src/authority/storage/sqlite.py
import sqlite3
import logging
import datetime
import json
import re # For safe field updates
from typing import Optional, Dict, Any, List, Tuple, Union

from .base import StorageInterface
from ..exceptions import DatabaseError

logger = logging.getLogger("authority.storage.sqlite")

# Helper to convert Row objects to dictionaries
def _row_to_dict(row: Optional[sqlite3.Row]) -> Optional[Dict[str, Any]]:
    return dict(row) if row else None

def _datetime_to_iso(dt: Optional[datetime.datetime]) -> Optional[str]:
    return dt.isoformat() if dt else None

def _iso_to_datetime(iso_str: Optional[str]) -> Optional[datetime.datetime]:
    return datetime.datetime.fromisoformat(iso_str) if iso_str else None

class SQLiteStorage(StorageInterface):
    """SQLite implementation of the StorageInterface."""

    def __init__(self, db_path: str):
        self.db_path = db_path
        self.conn = None
        self.cursor = None
        try:
            # Using PARSE_DECLTYPES for potential automatic type conversion (dates, etc.)
            # check_same_thread=False is often needed for web frameworks, but requires careful write synchronization.
            self.conn = sqlite3.connect(self.db_path,
                                        detect_types=sqlite3.PARSE_DECLTYPES | sqlite3.PARSE_COLNAMES,
                                        check_same_thread=False)
            self.conn.row_factory = sqlite3.Row
            # Improve concurrency and reliability
            self.conn.execute("PRAGMA foreign_keys = ON;")
            self.conn.execute("PRAGMA journal_mode=WAL;")
            self.cursor = self.conn.cursor()
            logger.info(f"SQLite connection established to {db_path}")
            self.initialize_schema() # Ensure schema exists on init
        except sqlite3.Error as e:
            logger.exception(f"Failed to connect/initialize SQLite database at {db_path}", exc_info=True)
            raise DatabaseError(f"SQLite connection failed: {e}")

    def close(self):
        if self.conn:
            try:
                self.conn.commit() # Ensure any pending changes are saved
                self.conn.close()
                logger.info(f"SQLite connection closed for {self.db_path}")
                self.conn = None
                self.cursor = None
            except sqlite3.Error as e:
                logger.error(f"Error closing SQLite connection: {e}", exc_info=True)

    def _execute(self, query: str, params: tuple = ()) -> sqlite3.Cursor:
        """Helper to execute queries, handling potential connection issues."""
        if not self.conn or not self.cursor:
             raise DatabaseError("Database connection is not available.")
        try:
            logger.debug(f"Executing SQL: {query} | Params: {params}")
            return self.cursor.execute(query, params)
        except sqlite3.Error as e:
            logger.error(f"SQLite error executing query: {query} | Params: {params} | Error: {e}", exc_info=True)
            raise DatabaseError(f"SQLite query failed: {e}")

    def _commit(self):
        """Helper to commit transaction."""
        if not self.conn: raise DatabaseError("Database connection is not available.")
        try:
            self.conn.commit()
        except sqlite3.Error as e:
            logger.error(f"SQLite commit failed: {e}", exc_info=True)
            raise DatabaseError(f"SQLite commit failed: {e}")

    def _rollback(self):
        """Helper to rollback transaction."""
        if not self.conn: return
        try:
            self.conn.rollback()
        except sqlite3.Error as e:
            logger.error(f"SQLite rollback failed: {e}", exc_info=True)

    def _add_missing_columns(self, table_name: str, columns_to_add: Dict[str, str]):
        """Adds columns to a table if they don't exist. Internal helper."""
        try:
            cursor = self._execute(f"PRAGMA table_info({table_name})")
            existing_columns = [row['name'] for row in cursor.fetchall()]

            for col_name, col_definition in columns_to_add.items():
                if col_name not in existing_columns:
                    try:
                        self._execute(f"ALTER TABLE {table_name} ADD COLUMN {col_name} {col_definition}")
                        logger.info(f"Added missing column '{col_name}' to SQLite table '{table_name}'.")
                    except sqlite3.OperationalError as alter_err:
                        if "duplicate column name" in str(alter_err):
                             logger.warning(f"Column '{col_name}' likely already added to '{table_name}' concurrently.")
                        else:
                             raise alter_err
            # Commit potentially added columns immediately after trying to add them
            # self._commit() # Let the main initialize_schema commit
        except sqlite3.Error as e:
             logger.error(f"Error checking/adding columns to table '{table_name}': {e}", exc_info=True)

    def update_user(self, user_id: int, updates: Dict[str, Any]) -> bool:
        if not updates: return True
        fields = []
        params = []
        for key, value in updates.items():
            if not re.match(r'^[a-zA-Z0-9_]+$', key): raise ValueError(f"Invalid field name: {key}")
            # Handle special types before appending
            if key in ['email', 'pending_email'] and isinstance(value, str):
                value = value.lower()
            elif isinstance(value, datetime.datetime):
                value = _datetime_to_iso(value)
            elif isinstance(value, bool):
                 value = 1 if value else 0 # Store booleans as 0/1

            fields.append(f"{key} = ?")
            params.append(value)

        # Automatically update 'updated_at' via trigger, no need to add manually

        params.append(user_id)
        query = f"UPDATE users SET {', '.join(fields)} WHERE id = ?"
        try:
            cursor = self._execute(query, tuple(params))
            self._commit()
            return cursor.rowcount > 0
        except sqlite3.IntegrityError as e:
            self._rollback(); logger.warning(f"Integrity error updating user {user_id}: {e}."); raise
        except sqlite3.Error as e:
             self._rollback(); raise DatabaseError(f"SQLite error updating user {user_id}: {e}")

        # Used for rotation: update hash and expiry of the *same* token record
        try:
            cursor = self._execute('''
                UPDATE refresh_tokens SET token_hash = ?, expires_at = ?, revoked = FALSE
                WHERE id = ?
            ''', (new_hash, _datetime_to_iso(new_expires_at), token_id))
            # No commit here? Let the calling operation commit. Check logic in core.py
            if cursor.rowcount == 0:
                 logger.warning(f"Attempted to rotate non-existent refresh token ID {token_id}")
                 raise InvalidTokenError(f"Refresh token ID {token_id} not found for rotation.")
            # Commit should happen in AuthManager.refresh_access_token AFTER update
        except sqlite3.IntegrityError as e: # Hash collision? Very unlikely
            self._rollback()
            logger.error(f"Integrity error rotating refresh token ID {token_id}: {e}")
            raise DatabaseError(f"Failed to rotate refresh token due to collision: {e}")
        except sqlite3.Error as e:

    """Gets a Fernet instance, initializing from env variable or override."""
    global _fernet_instance
    # Allow re-initialization if key changes (e.g., in tests or key rotation scenario)

    if _fernet_instance is None:

        try:
             fernet_key_bytes = fernet_key_str.encode('utf-8')

             import base64
             decoded_key = base64.urlsafe_b64decode(fernet_key_bytes)

    try:
        fernet = _get_fernet(fernet_key_override)
        encrypted_bytes = fernet.encrypt(data.encode('utf-8'))
        return encrypted_bytes.decode('utf-8') # Store as string
    except Exception as e:
        logger.error(f"Encryption failed: {e}", exc_info=True)
        return None

    """Decrypts base64 encoded string data using the Fernet key."""
    if not encrypted_data: return None
    try:
        fernet = _get_fernet(fernet_key_override)
        decrypted_bytes = fernet.decrypt(encrypted_data.encode('utf-8'))
        return decrypted_bytes.decode('utf-8')

def check_password_pwned(password: str, api_key: Optional[str] = None, timeout: int = 5) -> Optional[int]:
    """
    Checks if a password appears in the HIBP database using the K-Anonymity API.
    Returns: Count if found (>=0), None if error occurred.
    """
    if not password: return None
    try:
        sha1_hash = hashlib.sha1(password.encode('utf-8')).hexdigest().upper()
        prefix, suffix = sha1_hash[:5], sha1_hash[5:]
        url = f"{HIBP_API_URL}{prefix}"
        headers = {"User-Agent": "authority-library/1.3 (Python; +https://github.com/rkstudio585/authority)"}
        if api_key: headers["Hibp-Api-Key"] = api_key

        response = requests.get(url, headers=headers, timeout=timeout)
        response.raise_for_status()

        hashes = response.text.splitlines()
        for h_line in hashes:
            try:
                h_suffix, count_str = h_line.strip().split(':', 1)
                if h_suffix == suffix: return int(count_str)
            except ValueError: continue # Ignore lines that don't parse correctly
        return 0 # Prefix found, suffix not found
    except requests.exceptions.Timeout:
         logger.error(f"HIBP API request timed out after {timeout} seconds.")
         return None
    except requests.exceptions.RequestException as e:
        logger.error(f"HIBP API request failed: {e}")
        return None
    except ValueError:
        logger.error("HIBP API response parsing error (invalid count).")
        return None
    except Exception as e:
        logger.error(f"Unexpected error during HIBP check: {e}", exc_info=True)
        return None

        details = kwargs.get('details')
        details_json = None
        if details is not None:

    # --- Hashing & Validation ---
    def _hash_password(self, password: str) -> str:
        return pwd_context.hash(password)

    def _verify_password(self, plain_password: str, hashed_password: str) -> bool:
        try: return pwd_context.verify(plain_password, hashed_password)
        except Exception: return False # Invalid hash format etc.

    def _is_password_in_history(self, user_id: int, new_password: str) -> bool:
        history_depth = self.config.get("PASSWORD_HISTORY_DEPTH", 0)
        if history_depth <= 0: return False
        try:
            recent_hashes = self.storage.get_password_history(user_id, history_depth)
            for old_hash in recent_hashes:
                if self._verify_password(new_password, old_hash):
                    logger.warning(f"Password reuse attempt detected for user ID {user_id}.")
                    return True
        except Exception as e:
             logger.error(f"Error checking password history for user {user_id}: {e}")
        return False

    def _validate_password(self, password: str, email: Optional[str] = None, name: Optional[str] = None, user_id: Optional[int] = None):
        """Enhanced password validation including complexity, HIBP, history, and common patterns."""
        min_len = self.config['PASSWORD_MIN_LENGTH']
        if not password or len(password) < min_len:
            raise ValidationError(f"Password must be at least {min_len} characters long.")

        if self.config['PASSWORD_REQUIRE_COMPLEXITY']:
            regex = self.config['PASSWORD_COMPLEXITY_REGEX']
            desc = self.config['PASSWORD_COMPLEXITY_DESC']
            if not re.match(regex, password): raise ValidationError(desc)

        if self.config.get("PASSWORD_PREVENT_EMAIL_USERNAME_USE"):
             if email and email.split('@')[0].lower() in password.lower(): # Check username part too
                 raise ValidationError("Password cannot contain your email username.")
             if name and name.lower() in password.lower(): # Simplistic name check
                 raise ValidationError("Password cannot contain your name.")

        if self.config.get("HIBP_CHECK_ENABLED"):
            pwned_count = check_password_pwned(password, api_key=self.config.get("HIBP_API_KEY"))
            if pwned_count is None:
                if self.config.get("HIBP_FAILURE_MODE") == "block":
                    self._log_audit("PASSWORD_HIBP_CHECK_ERROR", ..., success=False, details={"mode": "block"})
                    raise ValidationError("Password security check unavailable.")
                else:
                    self._log_audit("PASSWORD_HIBP_CHECK_ERROR", ..., success=None, details={"mode": "ignore"})
                    logger.warning("HIBP check failed, proceeding (HIBP_FAILURE_MODE='ignore').")
            elif pwned_count > 0:
                self._log_audit("PASSWORD_HIBP_CHECK_PWNED", ..., success=False, details={"count": pwned_count})
                raise PasswordPwnedError(f"Password found in breaches {pwned_count:,} times; choose a different one.")

        if user_id is not None and self._is_password_in_history(user_id, password):
             raise ValidationError(f"Cannot reuse one of your last {self.config['PASSWORD_HISTORY_DEPTH']} passwords.")

    # --- JWT & Refresh Token Generation/Verification ---
    def _generate_access_token(self, user_id: int, email: str, roles: List[str], permissions: List[str]) -> str:
        secret = self.config["JWT_SECRET_KEY"]
        now = datetime.datetime.now(datetime.timezone.utc)
        exp = now + datetime.timedelta(minutes=self.config['JWT_ACCESS_TOKEN_EXPIRY_MINUTES'])
        payload = {
            'token_type': 'access', 'sub': user_id, 'email': email,
            'roles': roles, 'perms': permissions, # Include roles & effective permissions
            'iat': now, 'exp': exp, 'jti': secrets.token_hex(16) # Unique Token ID
        }
        return jwt.encode(payload, secret, algorithm=self.config['JWT_ALGORITHM'])

    def _generate_refresh_token(self, user_id: int, ip_address: Optional[str] = None, user_agent: Optional[str] = None) -> str:
        raw_token = generate_secure_token(byte_length=48)
        token_hash = hash_token(raw_token)
        expires_at = _get_datetime_after(days=self.config['JWT_REFRESH_TOKEN_EXPIRY_DAYS'])
        self.storage.store_refresh_token(user_id, token_hash, expires_at, ip_address, user_agent)
        return raw_token

    def verify_access_token(self, token: str) -> Optional[Dict[str, Any]]:
        secret = self.config["JWT_SECRET_KEY"]
        try:
            payload = jwt.decode(token, secret, algorithms=[self.config['JWT_ALGORITHM']], options={"require": ["exp", "iat", "sub", "token_type"]})
            if payload.get('token_type') != 'access': return None
            # Optional: Add DB check for user status
            return payload
        except jwt.ExpiredSignatureError: logger.info("Access token expired."); return None
        except jwt.InvalidTokenError as e: logger.warning(f"Invalid access token: {e}"); return None
        except Exception as e: logger.error(f"Access token verification error: {e}", exc_info=True); return None

    def refresh_access_token(self, refresh_token: str, ip_address: Optional[str] = None, user_agent: Optional[str] = None) -> Dict[str, str]:
        if not refresh_token: raise InvalidTokenError("Refresh token missing.")
        token_hash = hash_token(refresh_token)
        token_data = self.storage.get_refresh_token_by_hash(token_hash)

        # --- Validation ---
        if not token_data: raise InvalidTokenError("Invalid refresh token.")
        if token_data['revoked']: raise InvalidTokenError("Refresh token revoked.")
        if _is_expired(_iso_to_datetime(token_data['expires_at'])): # Handle stored ISO date
             # Optionally prune here
             raise TokenExpiredError("Refresh token expired.")
        user = self.storage.get_user_by_id(token_data['user_id'])
        if not user or not user['is_active']:
             if token_data: self.storage.revoke_refresh_token(token_data['id']) # Revoke if user gone
             raise UserNotFoundError("User not found or inactive.")

        # --- Issue new tokens ---
        user_id = user['id']
        user_roles = self.storage.get_user_roles(user_id)
        role_names = [r['name'] for r in user_roles]
        user_perms = self.storage.get_user_permissions(user_id) # Get effective perms
        new_access_token = self._generate_access_token(user_id, user['email'], role_names, user_perms)

        response = {"access_token": new_access_token, "token_type": "bearer"}
        rotated = False
        new_refresh_token_value = None

        # --- Rotation ---
        if self.config.get("REFRESH_TOKEN_ROTATE"):
            try:
                new_raw_token = generate_secure_token(byte_length=48)
                new_hash = hash_token(new_raw_token)
                new_expires = _get_datetime_after(days=self.config['JWT_REFRESH_TOKEN_EXPIRY_DAYS'])
                # Attempt to update existing token record atomically (or near-atomically)
                self.storage.update_refresh_token_usage(token_data['id'], new_hash, new_expires)
                new_refresh_token_value = new_raw_token # Set the new token to be returned
                rotated = True
            except Exception as e:
                 logger.error(f"Refresh token rotation failed for token ID {token_data['id']}: {e}", exc_info=True)
                 # Decide: Proceed without rotation or fail entirely? Let's proceed but log.
        else:
             # Update IP/UserAgent on existing token if not rotating? Optional.
             pass

        if rotated and new_refresh_token_value:
            response["refresh_token"] = new_refresh_token_value

        self._log_audit("REFRESH_TOKEN_SUCCESS", user_id=user_id, email=user['email'], ip_address=ip_address, success=True, details={"token_id": token_data['id'], "rotated": rotated})
        self._trigger_event("on_token_refreshed", {"user_id": user_id, "email": user['email'], "rotated": rotated})
        return response

    # --- Core Actions ---
    def register(self, name: str, email: str, password: str, ip_address: Optional[str] = None,
                 default_role_override: Optional[str] = None) -> Tuple[int, Optional[str]]:
        email_lower = email.lower()
        if not name or len(name.strip()) < 2: raise ValidationError("Name too short.")
        if not validate_email_format(email_lower): raise ValidationError("Invalid email format.")
        if self.storage.get_user_by_email(email_lower):
            self._log_audit("REGISTER_ATTEMPT_FAILURE", email=email_lower, ip_address=ip_address, success=False, details={"reason": "Email exists"})
            raise UserExistsError(f"Email '{email_lower}' already registered.")

        self._validate_password(password, email=email_lower, name=name) # HIBP/History check (no history for new user)

        hashed_password = self._hash_password(password)
        verification_token, v_token_hash, v_expiry, is_verified = None, None, None, not self.config['EMAIL_VERIFICATION_REQUIRED']
        if not is_verified:
            verification_token = generate_secure_token()
            v_token_hash = hash_token(verification_token)
            v_expiry = _get_datetime_after(minutes=self.config['VERIFICATION_TOKEN_EXPIRY_MINUTES'])

        default_role = default_role_override or self.config['DEFAULT_USER_ROLE']

        try:
            user_id = self.storage.create_user(
                name=name.strip(), email=email_lower, password_hash=hashed_password,
                role=default_role, is_verified=is_verified,
                verification_token_hash=v_token_hash, verification_token_expiry=v_expiry
            )
            # Add password to history
            self.storage.add_password_history(user_id, hashed_password)

            self._log_audit("REGISTER_SUCCESS", user_id=user_id, email=email_lower, ip_address=ip_address, success=True, details={"verified": is_verified, "role": default_role})
            self._trigger_event("on_user_registered", {"user_id": user_id, "email": email_lower, "name": name, "verification_token": verification_token, "is_verified": is_verified})
            logger.info(f"User '{email_lower}' (ID: {user_id}) registered. Role: {default_role}, Verified: {is_verified}.")
            return user_id, verification_token
        except Exception as e:
             self._log_audit("REGISTER_ATTEMPT_FAILURE", email=email_lower, ip_address=ip_address, success=False, details={"reason": f"Storage Error: {e}"})
             logger.error(f"Registration storage failed for '{email_lower}': {e}", exc_info=True)
             if "UNIQUE constraint failed: users.email" in str(e): raise UserExistsError(f"Email '{email_lower}' already registered.")
             raise DatabaseError(f"Failed register user: {e}")


    def login(self, email: str, password: str, ip_address: Optional[str] = None, user_agent: Optional[str] = None) -> Dict[str, Any]:
        """ Logs in a user. Returns tokens or MFA requirement."""
        email_lower = email.lower()
        if not validate_email_format(email_lower): raise ValidationError("Invalid email format.")
        if not password: raise ValidationError("Password required.")

        user = self.storage.get_user_by_email(email_lower)
        if not user: self._log_audit("LOGIN_FAILURE", email=email_lower, ip_address=ip_address, success=False, details={"reason": "User not found"}); raise UserNotFoundError("Email not found.")
        user_id = user['id']

        # --- Status Checks ---
        locked_until_dt = _iso_to_datetime(user['locked_until']) if user.get('locked_until') else None
        if locked_until_dt and not _is_expired(locked_until_dt):
            self._log_audit("LOGIN_FAILURE", ..., details={"reason": "Account locked"}); raise AccountLockedError(f"Account locked until {locked_until_dt.isoformat()}.")
        if not user['is_active']: self._log_audit("LOGIN_FAILURE", ..., details={"reason": "Inactive"}); raise AccountInactiveError("Account inactive.")
        if self.config['EMAIL_VERIFICATION_REQUIRED'] and not user['is_verified']: self._log_audit("LOGIN_FAILURE", ..., details={"reason": "Unverified"}); raise AccountNotVerifiedError("Email not verified.")

        # --- Password Verify ---
        if self._verify_password(password, user['password_hash']):
            # Reset failed attempts if any
            updates = {}
            if user['failed_login_attempts'] > 0: updates['failed_login_attempts'] = 0
            if user['last_failed_login']: updates['last_failed_login'] = None
            if user['locked_until']: updates['locked_until'] = None
            if updates: try: self.storage.update_user(user_id, updates) except Exception as e: logger.error(f"Failed reset login attempts {user_id}: {e}")

            # --- MFA Check ---
            if user['mfa_enabled']:
                self._log_audit("LOGIN_MFA_REQUIRED", user_id=user_id, email=email_lower, ip_address=ip_address, success=None)
                return {"status": "mfa_required", "user_id": user_id, "email": email_lower}
            else:
                # Login success without MFA
                user_roles = self.storage.get_user_roles(user_id); role_names = [r['name'] for r in user_roles]
                user_perms = self.storage.get_user_permissions(user_id)
                access_token = self._generate_access_token(user_id, email_lower, role_names, user_perms)
                refresh_token = self._generate_refresh_token(user_id, ip_address, user_agent)
                self._log_audit("LOGIN_SUCCESS", user_id=user_id, email=email_lower, ip_address=ip_address, success=True)
                self._trigger_event("on_login_success", {"user_id": user_id, "email": email_lower, "ip_address": ip_address, "method": "password"})
                return {"status": "success", "access_token": access_token, "refresh_token": refresh_token, "token_type": "bearer"}
        else:
            # --- Handle Failed Attempt ---
            try:
                new_attempts = user['failed_login_attempts'] + 1
                now_dt = datetime.datetime.now(datetime.timezone.utc)
                updates = {'failed_login_attempts': new_attempts, 'last_failed_login': _datetime_to_iso(now_dt)}
                new_locked_until = locked_until_dt # Keep existing lock if already set
                lockout_threshold = self.config['FAILED_LOGIN_LOCKOUT_THRESHOLD']
                if not new_locked_until and lockout_threshold > 0 and new_attempts >= lockout_threshold:
                     lock_minutes = self.config['FAILED_LOGIN_LOCKOUT_MINUTES']
                     new_locked_until = _get_datetime_after(minutes=lock_minutes)
                     updates['locked_until'] = _datetime_to_iso(new_locked_until)
                     self._log_audit("ACCOUNT_LOCKED", user_id=user_id, email=email_lower, ip_address=ip_address, success=None, details={"attempts": new_attempts, "locked_until": updates['locked_until']})
                self.storage.update_user(user_id, updates)
            except Exception as e: logger.error(f"Failed update failed attempts {user_id}: {e}")

            self._log_audit("LOGIN_FAILURE", user_id=user_id, email=email_lower, ip_address=ip_address, success=False, details={"reason": "Invalid password"})
            raise InvalidCredentialsError("Invalid email or password.")

    # --- MFA Methods ---
    def setup_mfa(self, email: str) -> str:
        """Generates MFA secret (encrypted) and provisioning URI."""
        email_lower = email.lower()
        user = self.storage.get_user_by_email(email_lower)
        if not user: raise UserNotFoundError(f"User '{email_lower}' not found.")
        user_id = user['id']
        if user['mfa_enabled']: raise ValidationError("MFA is already enabled.")

        mfa_secret_base32 = pyotp.random_base32()
        encrypted_secret = self._encrypt(mfa_secret_base32)
        if not encrypted_secret:
            self._log_audit("MFA_SETUP_FAILURE", user_id=user_id, email=email_lower, success=False, details={"reason": "Encryption failed"})
            raise ConfigurationError("MFA setup failed due to encryption error (check Fernet key).")

        issuer = self.config['MFA_ISSUER_NAME']
        provisioning_uri = pyotp.totp.TOTP(mfa_secret_base32).provisioning_uri(name=email_lower, issuer_name=issuer)

        try:
            updated = self.storage.update_user(user_id, {'mfa_secret_encrypted': encrypted_secret, 'mfa_enabled': False}) # Not enabled yet
            if not updated: raise DatabaseError("Failed to store MFA secret.")
            self._log_audit("MFA_SETUP_INITIATED", user_id=user_id, email=email_lower, success=True)
            self._trigger_event("on_mfa_setup_initiated", {"user_id": user_id, "email": email_lower})
            logger.info(f"MFA secret generated for user '{email_lower}'. Awaiting verification.")
            return provisioning_uri # Only return URI
        except Exception as e: self._log_audit("MFA_SETUP_FAILURE", ...); raise DatabaseError(f"Failed initiate MFA setup: {e}")

    def verify_and_enable_mfa(self, email: str, mfa_code: str) -> List[str]:
        """ Verifies MFA code during setup, enables MFA, generates recovery codes. Returns recovery codes. """
        email_lower = email.lower()
        user = self.storage.get_user_by_email(email_lower)
        if not user: raise UserNotFoundError(...)
        user_id = user['id']
        if user['mfa_enabled']: logger.info(f"MFA already enabled for {email_lower}."); return [] # Return empty list if already enabled
        if not user['mfa_secret_encrypted']: raise MFANotEnabledError("MFA setup not initiated.")

        decrypted_secret = self._decrypt(user['mfa_secret_encrypted'])
        if not decrypted_secret: raise ConfigurationError("MFA verification failed (decryption error).")

        totp = pyotp.TOTP(decrypted_secret)
        if totp.verify(mfa_code):
            try:
                updated = self.storage.update_user(user_id, {'mfa_enabled': True})
                if not updated: raise DatabaseError("Failed to mark MFA as enabled.")
                # Generate and set recovery codes immediately after enabling
                recovery_codes = self.generate_and_set_mfa_recovery_codes(user_id) # This logs/triggers event
                self._log_audit("MFA_ENABLED", user_id=user_id, email=email_lower, success=True)
                self._trigger_event("on_mfa_enabled", {"user_id": user_id, "email": email_lower})
                logger.info(f"MFA successfully enabled for '{email_lower}'.")
                return recovery_codes # Return plain recovery codes
            except Exception as e: raise DatabaseError(f"Failed finalize MFA enablement: {e}")
        else:
            self._log_audit("MFA_ENABLE_FAILURE", ..., details={"reason": "Invalid code"}); raise MFAFailedError("Invalid MFA code during setup.")

    def verify_mfa_login(self, user_id: int, mfa_code: str, ip_address: Optional[str] = None, user_agent: Optional[str] = None) -> Dict[str, Any]:
        """ Verifies TOTP or Recovery code during login. Returns tokens on success."""
        user = self.storage.get_user_by_id(user_id)
        if not user: raise UserNotFoundError(...)
        email = user['email']
        if not user['mfa_enabled']: raise MFANotEnabledError("MFA not enabled.") # Should not happen if called correctly

        # 1. Try TOTP
        totp_verified = False
        if user['mfa_secret_encrypted']:
            decrypted_secret = self._decrypt(user['mfa_secret_encrypted'])
            if decrypted_secret:
                 totp = pyotp.TOTP(decrypted_secret)
                 if totp.verify(mfa_code, valid_window=1): totp_verified = True
            else: logger.error(f"MFA login failed User {user_id}: Decryption error.")

        # 2. Try Recovery Code if TOTP failed
        recovery_verified = False
        if not totp_verified:
             recovery_verified = self.verify_mfa_recovery_code(user_id, mfa_code) # This logs success/failure internally

        if not totp_verified and not recovery_verified:
            self._log_audit("LOGIN_FAILURE_MFA", user_id=user_id, email=email, ip_address=ip_address, success=False, details={"reason": "Invalid TOTP or Recovery Code"})
            raise MFAFailedError("Invalid MFA code or recovery code.")

        # --- MFA Passed ---
        method = "mfa_recovery" if recovery_verified else "mfa_totp"
        logger.info(f"MFA login success User {user_id} via {method}.")
        user_roles = self.storage.get_user_roles(user_id); role_names = [r['name'] for r in user_roles]
        user_perms = self.storage.get_user_permissions(user_id)
        access_token = self._generate_access_token(user_id, email, role_names, user_perms)
        refresh_token = self._generate_refresh_token(user_id, ip_address, user_agent)
        self._log_audit("LOGIN_SUCCESS_MFA", user_id=user_id, email=email, ip_address=ip_address, success=True, details={"method": method})
        self._trigger_event("on_login_success", {"user_id": user_id, "email": email, "ip_address": ip_address, "method": method})
        return {"status": "success", "access_token": access_token, "refresh_token": refresh_token, "token_type": "bearer"}

    def disable_mfa(self, email: str, password: str, ip_address: Optional[str] = None) -> bool:
        email_lower = email.lower()
        user = self.storage.get_user_by_email(email_lower)
        if not user: raise UserNotFoundError(...)
        user_id = user['id']
        if not user['mfa_enabled']: raise MFANotEnabledError("MFA not enabled.")
        if not self._verify_password(password, user['password_hash']):
             self._log_audit("MFA_DISABLE_FAILURE", ..., details={"reason": "Invalid password"}); raise InvalidCredentialsError("Incorrect password.")
        try:
            # Remove secret, disable flag, clear recovery codes
            updated = self.storage.update_user(user_id, {'mfa_enabled': False, 'mfa_secret_encrypted': None})
            if not updated: raise DatabaseError("Failed to update MFA status.")
            self.storage.set_mfa_recovery_codes(user_id, []) # Clear codes
            self._log_audit("MFA_DISABLED", user_id=user_id, email=email_lower, ip_address=ip_address, success=True)
            self._trigger_event("on_mfa_disabled", {"user_id": user_id, "email": email_lower})
            return True
        except Exception as e: self._log_audit("MFA_DISABLE_FAILURE", ...); raise DatabaseError(f"Failed to disable MFA: {e}")

    def generate_and_set_mfa_recovery_codes(self, user_id: int) -> List[str]:
        """ Generates, hashes, stores, and returns new plain text recovery codes. """
        user = self.storage.get_user_by_id(user_id)
        if not user or not user['mfa_enabled']: raise MFANotEnabledError("User not found or MFA not enabled.")
        code_count = self.config.get("MFA_RECOVERY_CODE_COUNT", 10)
        plain_codes = [generate_secure_token(byte_length=8).upper()[:10] for _ in range(code_count)]
        hashed_codes = [hash_token(code) for code in plain_codes]
        try:
            self.storage.set_mfa_recovery_codes(user_id, hashed_codes) # Replaces old codes
            self._log_audit("MFA_RECOVERY_CODES_GENERATED", user_id=user_id, email=user.get('email'), success=True, details={"count": len(plain_codes)})
            self._trigger_event("on_mfa_recovery_codes_generated", {"user_id": user_id, "email": user.get('email'), "count": len(plain_codes)})
            logger.info(f"Generated {len(plain_codes)} recovery codes for user ID {user_id}.")
            return plain_codes
        except Exception as e: self._log_audit("MFA_RECOVERY_CODES_FAILURE", ...); raise DatabaseError(f"Failed set recovery codes: {e}")

    def verify_mfa_recovery_code(self, user_id: int, recovery_code: str) -> bool:
        """ Verifies and consumes a recovery code. Internal use or direct call. """
        if not recovery_code: return False
        hashed_code = hash_token(recovery_code)
        try:
            used = self.storage.use_mfa_recovery_code(user_id, hashed_code)
            # Audit logging happens within the login flow or if called directly
            return used
        except Exception as e: logger.error(f"Error verifying recovery code {user_id}: {e}"); return False

                    user_verification=self.config['WEBAUTHN_USER_VERIFICATION'],
                    # resident_key=ResidentKeyRequirement.REQUIRED, # If discoverable credentials needed
                    # authenticator_attachment=AuthenticatorAttachment.CROSS_PLATFORM, # If only external keys desired
                ),
                timeout=self.config['WEBAUTHN_TIMEOUT_MS'],
                attestation="none" # Usually 'none' is sufficient unless attestation needed
            )
            # IMPORTANT: The application MUST store options["challenge"] associated with the user's session.
            self._log_audit("WEBAUTHN_REGISTRATION_BEGIN", user_id=user_id, email=user['email'], success=True)
            return options # Return PublicKeyCredentialCreationOptions as dict
        except Exception as e: raise WebAuthnRegistrationError(f"Failed begin WebAuthn registration: {e}")

    def complete_webauthn_registration(self, user_id: int, registration_response: Dict[str, Any], stored_challenge: str, description: Optional[str] = None) -> bool:
        """Verifies the client's registration response and saves the credential."""
        rp_id = self.config.get("WEBAUTHN_RP_ID")
        expected_origin = self.config.get("WEBAUTHN_EXPECTED_ORIGIN")
        if not rp_id or not expected_origin: raise ConfigurationError("WebAuthn RP ID/Origin missing.")

        user = self.storage.get_user_by_id(user_id)
        if not user: raise UserNotFoundError("User not found.")
        user_handle = str(user_id).encode('utf-8')

        try:
            # Ensure response structure matches expected input for verify_registration_response
            # The library might expect specific types (e.g., bytes for id/rawId)
            # registration_response['id'] = base64url_to_bytes(registration_response['id'])
            # registration_response['rawId'] = base64url_to_bytes(registration_response['rawId'])
            # if 'attestationObject' in registration_response['response']:
            #     registration_response['response']['attestationObject'] = base64url_to_bytes(registration_response['response']['attestationObject'])
            # if 'clientDataJSON' in registration_response['response']:
            #      registration_response['response']['clientDataJSON'] = base64url_to_bytes(registration_response['response']['clientDataJSON'])

            # Parse the raw dict into the library's expected structure if needed, or pass dict directly if supported
            credential_public_key = verify_registration_response(
                credential=registration_response, # Pass the raw dict from client JS
                expected_challenge=base64url_to_bytes(stored_challenge), # Challenge MUST match the one stored
                expected_origin=expected_origin,
                expected_rp_id=rp_id,
                require_user_verification=self.config['WEBAUTHN_USER_VERIFICATION'] == UserVerificationRequirement.REQUIRED
            )
            # Credential verified, store it
            self.storage.add_webauthn_credential(
                user_id=user_id, user_handle=user_handle,
                credential_id=credential_public_key.credential_id, # Already bytes
                public_key=credential_public_key.public_key, # Already bytes
                sign_count=credential_public_key.sign_count,
                rp_id=rp_id,
                transports=registration_response.get('response', {}).get('transports'),
                description=description
            )
            self._log_audit("WEBAUTHN_REGISTRATION_COMPLETE", ..., details={"credential_id": credential_public_key.credential_id.hex()})
            self._trigger_event("on_webauthn_credential_added", ...)
            return True
        except WebAuthnException as e: # Catch specific webauthn errors
             logger.warning(f"WebAuthn registration verify failed: {e}", exc_info=True)
             self._log_audit("WEBAUTHN_REGISTRATION_FAILURE", ..., details={"error": str(e)})
             raise WebAuthnVerificationError(f"WebAuthn registration failed: {e}")
        except Exception as e: # Catch other errors (parsing, storage)
             logger.error(f"WebAuthn registration completion error: {e}", exc_info=True)
             self._log_audit("WEBAUTHN_REGISTRATION_FAILURE", ..., details={"error": str(e)})
             raise WebAuthnVerificationError(f"WebAuthn registration failed: {e}")


    def begin_webauthn_authentication(self, email: Optional[str] = None) -> Dict[str, Any]:
        """Generates options for WebAuthn authentication (login)."""
        rp_id = self.config.get("WEBAUTHN_RP_ID")
        if not rp_id: raise ConfigurationError("WebAuthn RP ID not configured.")

        allow_credentials = []
        if email: # If email provided (RP-directed login)
            user = self.storage.get_user_by_email(email.lower())
            if user:
                user_id = user['id']
                user_creds = self.storage.get_webauthn_credentials_for_user(user_id, rp_id=rp_id)
                allow_credentials = [{"id": cred['credential_id'], "type": "public-key"} for cred in user_creds]
            else:
                 # User not found, still generate options but without allowCredentials (might allow resident key login)
                 logger.debug(f"WebAuthn login begin: Email '{email}' not found, allowing resident keys.")
        # If no email provided, rely on discoverable credentials (resident keys) - allow_credentials remains empty

        try:
            options = generate_authentication_options(
                rp_id=rp_id,
                allow_credentials=allow_credentials,
                user_verification=self.config['WEBAUTHN_USER_VERIFICATION'],
                timeout=self.config['WEBAUTHN_TIMEOUT_MS']
            )
            # IMPORTANT: The application MUST store options["challenge"] associated with the potential login attempt.
            self._log_audit("WEBAUTHN_AUTHENTICATION_BEGIN", email=email, success=True)
            return options
        except Exception as e: raise WebAuthnVerificationError(f"Failed begin WebAuthn authentication: {e}")

    def complete_webauthn_authentication(self, authentication_response: Dict[str, Any], stored_challenge: str,
                                        ip_address: Optional[str] = None, user_agent: Optional[str] = None) -> Dict[str, Any]:
        """Verifies the client's authentication response and returns login tokens."""
        rp_id = self.config.get("WEBAUTHN_RP_ID")
        expected_origin = self.config.get("WEBAUTHN_EXPECTED_ORIGIN")
        if not rp_id or not expected_origin: raise ConfigurationError("WebAuthn RP ID/Origin missing.")

        try:
            credential_id_bytes = base64url_to_bytes(authentication_response['id'])
            # Retrieve the stored credential information from DB
            stored_credential = self.storage.get_webauthn_credential_by_id(credential_id_bytes)
            if not stored_credential:
                 raise WebAuthnVerificationError("Authenticator not registered.")

            # Verify the authentication response
            auth_result = verify_authentication_response(
                response=authentication_response, # Pass raw dict from client JS
                expected_challenge=base64url_to_bytes(stored_challenge),
                expected_rp_id=rp_id,
                expected_origin=expected_origin,
                credential_public_key=stored_credential['public_key'],
                credential_current_sign_count=stored_credential['sign_count'],
                require_user_verification=self.config['WEBAUTHN_USER_VERIFICATION'] == UserVerificationRequirement.REQUIRED
            )

            # --- Authentication Success ---
            user_id = stored_credential['user_id']
            user = self.storage.get_user_by_id(user_id) # Get fresh user data
            if not user or not user['is_active']:
                 raise WebAuthnVerificationError("User associated with authenticator not found or inactive.")

            # Update sign count and last used timestamp
            self.storage.update_webauthn_credential_sign_count(credential_id_bytes, auth_result.new_sign_count)
            self.storage.update_webauthn_credential_last_used(credential_id_bytes)
            # Commit these storage updates
            try: self.storage._commit() # Accessing protected commit, better to have storage handle transactions
            except Exception as e: logger.error(f"Failed commit WebAuthn updates: {e}") # Log but proceed

            # Issue login tokens
            user_roles = self.storage.get_user_roles(user_id); role_names = [r['name'] for r in user_roles]
            user_perms = self.storage.get_user_permissions(user_id)
            access_token = self._generate_access_token(user_id, user['email'], role_names, user_perms)
            refresh_token = self._generate_refresh_token(user_id, ip_address, user_agent)

            self._log_audit("LOGIN_SUCCESS_WEBAUTHN", user_id=user_id, email=user['email'], ip_address=ip_address, success=True, details={"credential_id": credential_id_bytes.hex()})
            self._trigger_event("on_login_success", {"user_id": user_id, "email": user['email'], "ip_address": ip_address, "method": "webauthn"})
            return {"status": "success", "access_token": access_token, "refresh_token": refresh_token, "token_type": "bearer"}

        except WebAuthnException as e:
             logger.warning(f"WebAuthn authentication verify failed: {e}", exc_info=True)
             self._log_audit("WEBAUTHN_AUTHENTICATION_FAILURE", email=user.get('email') if 'user' in locals() else None, success=False, details={"error": str(e)})
             raise WebAuthnVerificationError(f"WebAuthn authentication failed: {e}")
        except Exception as e:
             logger.error(f"WebAuthn authentication completion error: {e}", exc_info=True)
             self._log_audit("WEBAUTHN_AUTHENTICATION_FAILURE", email=user.get('email') if 'user' in locals() else None, success=False, details={"error": str(e)})
             raise WebAuthnVerificationError(f"WebAuthn authentication failed: {e}")

    def delete_webauthn_credential(self, user_id: int, credential_id_b64url: str, ip_address: Optional[str] = None) -> bool:
         """Deletes a specific WebAuthn credential for the user."""
         try:
             credential_id_bytes = base64url_to_bytes(credential_id_b64url)
             deleted = self.storage.delete_webauthn_credential(user_id, credential_id_bytes)
             if deleted:

                  self._trigger_event("on_webauthn_credential_deleted", {"user_id": user_id, "credential_id": credential_id_b64url})
             return deleted
         except Exception as e:

              raise DatabaseError(f"Failed to delete WebAuthn credential: {e}")

    # --- RBAC Methods ---
    def check_permission(self, user_id: int, required_permission: str) -> bool:
        try:

            logger.debug(f"Perm check user {user_id}, perm '{required_permission}': {has_perm}")

             raise InsufficientPermissionsError(f"Required permission denied: {required_permission}")

    # --- Session Management ---
    def list_sessions(self, user_id: int) -> List[Dict[str, Any]]:
        """ Lists active (non-revoked, non-expired) refresh tokens/sessions for a user. """
        try:
            tokens = self.storage.list_refresh_tokens_for_user(user_id)
            # Filter out expired/revoked in code if storage doesn't guarantee it
            active_sessions = []
            for t in tokens:
                 expiry = _iso_to_datetime(t['expires_at'])
                 if not t.get('revoked') and expiry and not _is_expired(expiry):
                      active_sessions.append({
                          "id": t['id'], # Internal DB ID of the token
                          "created_at": t['created_at'],
                          "expires_at": t['expires_at'],
                          "ip_address": t.get('ip_address'),
                          "user_agent": t.get('user_agent'),
                      })
            return active_sessions
        except Exception as e: raise DatabaseError(f"Failed list sessions user {user_id}: {e}")

    def revoke_session_by_id(self, user_id: int, session_token_id: int, ip_address: Optional[str] = None) -> bool:
        """Revokes a specific session (refresh token) by its internal ID, ensuring user owns it."""
        token_data = self.storage.get_refresh_token_by_id(session_token_id)
        if not token_data or token_data['user_id'] != user_id:
             logger.warning(f"User {user_id} attempt revoke unauthorized/non-existent session ID {session_token_id}")
             return False # Don't leak existence info
        revoked = self.storage.revoke_refresh_token(session_token_id)
        if revoked:
            self._log_audit("SESSION_REVOKED", user_id=user_id, ip_address=ip_address, success=True, details={"token_id": session_token_id})
            self._trigger_event("on_token_revoked", {"user_id": user_id, "token_type": "refresh", "token_id": session_token_id})
        return revoked

    def revoke_all_sessions_for_user(self, user_id: int, exclude_current_token_id: Optional[int] = None, ip_address: Optional[str] = None) -> int:
        """Revokes all active refresh tokens for a user, optionally excluding one."""
        count = self.storage.revoke_all_refresh_tokens_for_user(user_id, exclude_token_id=exclude_current_token_id)
        user = self.storage.get_user_by_id(user_id)
        email = user['email'] if user else None
        self._log_audit("ALL_SESSIONS_REVOKED", user_id=user_id, email=email, ip_address=ip_address, success=True, details={"count": count, "excluded": exclude_current_token_id})
        self._trigger_event("on_all_sessions_revoked", {"user_id": user_id, "email": email, "count": count})
        logger.info(f"Revoked {count} sessions for user ID {user_id}.")
        return count

`Authority` is a comprehensive Python library designed for building secure and flexible user authentication and authorization systems. It offers a wide range of features suitable for modern web applications and APIs, focusing on security best practices and developer convenience.

## Key Features

*   **Secure Password Handling:** Uses `passlib` with bcrypt for strong password hashing. Includes password complexity rules and optional checks against the 'Have I Been Pwned' database.
*   **Password History:** Prevents users from reusing recent passwords.
*   **JWT Authentication:** Issues short-lived JWT access tokens and longer-lived refresh tokens for robust session management.
    *   **Refresh Token Rotation:** Enhances security by automatically rotating refresh tokens upon use.
    *   **Session Management:** List and revoke active sessions (refresh tokens).
*   **Multi-Factor Authentication (MFA/2FA):**
    *   **TOTP:** Time-based One-Time Passwords (e.g., Google Authenticator, Authy) support.
    *   **Encrypted Secrets:** MFA secrets are encrypted at rest using Fernet (requires secure key management).
    *   **Recovery Codes:** Generate single-use recovery codes for account access if the authenticator is lost.
*   **WebAuthn/FIDO2 (Passkeys) Framework:** Provides the backend infrastructure (registration/authentication options generation and verification) for passwordless authentication using security keys or platform authenticators (e.g., Face ID, Windows Hello). *Requires client-side JavaScript integration.*
*   **Role-Based Access Control (RBAC):** Define roles and permissions, assign permissions to roles, and roles to users for granular authorization checks.
*   **API Key Management:** Generate, verify, list, and delete API keys for programmatic access.
*   **Account Lifecycle:**
    *   Email Verification flow.
    *   Secure Password Reset flow (token-based).
    *   Secure Email Address Change flow (token-based).
    *   Account Activation/Deactivation.
    *   Account Lockout after failed login attempts.
*   **Pluggable Storage Backend:** Includes a default `SQLiteStorage` implementation but defines a `StorageInterface` allowing easy adaptation to other databases (PostgreSQL, MySQL, etc.).
*   **Audit Trail:** Logs significant security events (logins, password changes, MFA changes, etc.) for monitoring.
*   **Custom User Profiles:** Store arbitrary JSON data associated with user profiles.
*   **Configuration:** Flexible configuration via Python dictionary or environment variables (recommended for secrets).
*   **Event Hooks:** Register listeners for key events (e.g., `on_user_registered`, `on_login_success`) for custom actions like sending emails.
*   **Asynchronous Ready:** Includes an `AsyncStorageInterface` definition to facilitate building asynchronous applications.

## Critical Security Configuration

**`Authority` requires secure configuration for sensitive keys.**

1.  **`AUTHORITY_JWT_SECRET_KEY` (Environment Variable or `config['JWT_SECRET_KEY']`)**
    *   **Purpose:** Used to sign and verify JWT access tokens.
    *   **Requirement:** MUST be a long, random, unpredictable string. Keep it secret!
    *   **Generation:** Use `openssl rand -hex 32` or a similar method to generate a strong key.
    *   **Management:** Load from environment variables or a dedicated secrets management system in production. **DO NOT COMMIT THIS KEY TO VERSION CONTROL.**

2.  **`AUTHORITY_FERNET_KEY` (Environment Variable or `config['FERNET_KEY']`)**
    *   **Purpose:** Used to encrypt and decrypt MFA TOTP secrets stored in the database.
    *   **Requirement:** MUST be a valid Fernet key (32 url-safe base64-encoded bytes). Keep it secret!
    *   **Generation:**
        ```python
        from cryptography.fernet import Fernet
        key = Fernet.generate_key()
        print(key.decode()) # Store this output securely
        ```
    *   **Management:** Load from environment variables or secrets management. **DO NOT COMMIT THIS KEY.** Loss of this key means inability to decrypt MFA secrets, requiring users to re-register MFA.

3.  **WebAuthn Configuration (`AUTHORITY_WEBAUTHN_RP_ID`, `AUTHORITY_WEBAUTHN_ORIGIN`)**
    *   **`RP_ID`:** Your website's domain name (e.g., `example.com`). MUST match the domain where WebAuthn operations occur.
    *   **`EXPECTED_ORIGIN`:** The full origin (scheme + domain + port if non-standard) from where WebAuthn requests are expected (e.g., `https://example.com`).

## Database Schema

The default `SQLiteStorage` creates the following tables (see `src/authority/storage/sqlite.py` for exact definitions and indexes):

*   `users`: Core user information, flags, tokens, MFA details, custom profile.
*   `password_history`: Stores recent hashed passwords for reuse prevention.
*   `refresh_tokens`: Stores hashed refresh tokens, expiry, and session metadata.
*   `mfa_recovery_codes`: Stores hashed single-use recovery codes.
*   `webauthn_credentials`: Stores registered WebAuthn authenticator details.
*   `api_keys`: Stores hashed API keys, metadata, and permissions.
*   `auth_audit_log`: Logs significant security events.
*   `roles`: Defines available roles.
*   `permissions`: Defines available permission codes.
*   `role_permissions`: Maps permissions to roles (Many-to-Many).
*   `user_roles`: Maps users to roles (Many-to-Many).

## Configuration Options

`Authority` can be configured by passing a dictionary to its constructor or by setting environment variables (prefixed with `AUTHORITY_`). Environment variables override defaults, and the constructor dictionary overrides both.

*   `DB_PATH`: Path to the SQLite database file (Default: `authority_data.db`).
*   `STORAGE_CLASS`: The class implementing `StorageInterface` (Default: `SQLiteStorage`).
*   `JWT_SECRET_KEY` (**Required**, Env: `AUTHORITY_JWT_SECRET_KEY`): Secret for signing JWTs.
*   `FERNET_KEY` (**Required**, Env: `AUTHORITY_FERNET_KEY`): Key for encrypting MFA secrets.
*   `JWT_ALGORITHM`: Algorithm for JWT signing (Default: `HS256`).
*   `JWT_ACCESS_TOKEN_EXPIRY_MINUTES`: Lifetime of access tokens (Default: 15).
*   `JWT_REFRESH_TOKEN_EXPIRY_DAYS`: Lifetime of refresh tokens (Default: 7).
*   `PASSWORD_MIN_LENGTH`: Minimum password length (Default: 12).
*   `PASSWORD_HISTORY_DEPTH`: Number of previous passwords to disallow reuse (Default: 5).
*   `PASSWORD_REQUIRE_COMPLEXITY`: Enforce complexity regex (Default: `True`).
*   `PASSWORD_COMPLEXITY_REGEX`: Regex for password validation.
*   `PASSWORD_COMPLEXITY_DESC`: User-friendly complexity description.
*   `PASSWORD_PREVENT_EMAIL_USERNAME_USE`: Disallow email/username in password (Default: `True`).
*   `HIBP_CHECK_ENABLED`: Check passwords against HaveIBeenPwned (Default: `False`).
*   `HIBP_API_KEY` (Env: `AUTHORITY_HIBP_KEY`): Optional API key for HIBP service.
*   `HIBP_OFFLINE_PATH`: Path to local HIBP password list file (alternative to API).
*   `HIBP_FAILURE_MODE`: Action on HIBP check error: `'ignore'` or `'block'` (Default: `ignore`).
*   `FAILED_LOGIN_LOCKOUT_THRESHOLD`: Number of failed logins before lockout (Default: 5).
*   `FAILED_LOGIN_LOCKOUT_MINUTES`: Duration of account lockout (Default: 15).
*   `EMAIL_VERIFICATION_REQUIRED`: Require email verification (Default: `True`).
*   `VERIFICATION_TOKEN_EXPIRY_MINUTES`: Lifetime of email verification tokens (Default: 1440).
*   `PASSWORD_RESET_TOKEN_EXPIRY_MINUTES`: Lifetime of password reset tokens (Default: 30).
*   `EMAIL_CHANGE_TOKEN_EXPIRY_MINUTES`: Lifetime of email change tokens (Default: 60).
*   `MFA_ISSUER_NAME`: Name shown in authenticator apps (Default: `Authority Powered App`).
*   `MFA_RECOVERY_CODE_COUNT`: Number of recovery codes generated (Default: 10).
*   `REFRESH_TOKEN_ROTATE`: Enable refresh token rotation (Default: `True`).
*   `WEBAUTHN_RP_ID` (**Required for WebAuthn**, Env: `AUTHORITY_WEBAUTHN_RP_ID`): Relying Party ID (your domain).
*   `WEBAUTHN_RP_NAME`: Display name for your application in WebAuthn prompts.
*   `WEBAUTHN_EXPECTED_ORIGIN` (**Required for WebAuthn**, Env: `AUTHORITY_WEBAUTHN_ORIGIN`): Expected browser origin.
*   `WEBAUTHN_TIMEOUT_MS`: Timeout for WebAuthn operations (Default: 60000).
*   `WEBAUTHN_USER_VERIFICATION`: WebAuthn user verification preference (Default: `UserVerificationRequirement.PREFERRED`).
*   `AUDIT_LOG_ENABLED`: Enable logging security events (Default: `True`).
*   `DEFAULT_USER_ROLE`: Name of the default role assigned during registration (Default: `user`).
*   `API_KEY_BYTE_LENGTH`: Randomness length for API keys (Default: 32).
*   `PRUNE_REFRESH_TOKENS_ON_STARTUP`: Clean expired tokens on init (Default: `True`).

## Event Hooks

Subscribe to events for custom actions:

```python
def my_login_handler(event_data):
    print(f"User {event_data['email']} logged in from IP {event_data['ip_address']}")

auth.add_event_listener("on_login_success", my_login_handler)
```

Available events include: `on_user_registered`, `on_login_success`, `on_token_refreshed`, `on_password_reset_request`, `on_password_reset_success`, `on_email_verified`, `on_email_change_request`, `on_email_change_confirmed`, `on_mfa_setup_initiated`, `on_mfa_enabled`, `on_mfa_disabled`, `on_mfa_recovery_codes_generated`, `on_mfa_recovery_code_used`, `on_webauthn_credential_added`, `on_webauthn_credential_deleted`, `on_api_key_created`, `on_api_key_deleted`, `on_token_revoked`, `on_all_sessions_revoked`, `on_profile_updated`, `on_user_assigned_to_role`, etc. (Check `_trigger_event` calls in `core.py`).

## WebAuthn Integration Notes

1.  **Client-Side:** You need JavaScript code using `navigator.credentials.create()` (for registration) and `navigator.credentials.get()` (for authentication). Pass the options generated by `begin_webauthn_registration` and `begin_webauthn_authentication` to these functions.
2.  **Challenge Storage:** The `challenge` value generated by the `begin_` methods MUST be stored securely in the user's temporary session state (e.g., server-side session, signed cookie) and retrieved for the corresponding `complete_` method verification.
3.  **Response Handling:** The response object from the client-side JS needs to be sent back to your server and passed (usually as a JSON-decoded dictionary) to the `complete_` methods. Ensure correct encoding/decoding (especially for base64url values like `id`, `rawId`, `challenge`).

## Custom Storage Backends

Implement the `authority.storage.StorageInterface` (or `AsyncStorageInterface`) abstract base class to use databases other than SQLite. Then pass your custom storage class or instance to the `AuthManager` constructor.
